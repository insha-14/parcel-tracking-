SWIFTSHIP - COURIER AND PARCEL TRACKING MANAGEMENT SYSTEM

WEBSITE PAGES
1. index.html       - Home page
2. book.html        - Create a parcel booking
3. track.html       - Search and view parcel tracking history
4. customers.html   - Add and view customer records
5. staff.html       - Delivery staff tracking updates
6. payments.html    - Record and view payments

HOW TO OPEN THE WEBSITE (EASY METHOD)
1. Extract the ZIP file.
2. Open the extracted courier_parcel_tracking folder.
3. Double-click index.html.
4. Use the navigation links at the top to open each separate page.

DEMO NOTE
The website's browser demo saves records in localStorage on the same browser/device.
It does not require npm, Express, or MySQL to view and demonstrate the pages.
If you clear browser site data, the demo records may be erased.

MYSQL DATABASE
1. Open MySQL Workbench.
2. Open schema.sql.
3. Click the lightning bolt (Execute).
4. The courier_db database and its four tables will be created:
   customers, parcels, tracking, payments.

IMPORTANT
This package is a multi-page front-end demo plus the MySQL schema.
The browser demo uses localStorage; it is not connected to MySQL.
